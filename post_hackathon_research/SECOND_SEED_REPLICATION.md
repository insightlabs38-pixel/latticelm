# Second-seed replication decisions

The 16M Co4/dense pair was run: evidence and measured-time gates passed.
The selected mechanism pair was gated out: no promotable 16M mechanism.
Each launched pair uses seed 2026, 150M logical tokens per arm, a fresh WSD trajectory, the same DATA-D corpus and order, and the common evaluator. The controller budgets both endpoints and protects later named stretch work before launch.

At 150M, second-seed Co4 minus dense held-out loss was -0.00211, BPB -0.00694, and four-task raw accuracy -0.0065.
