This records **runnable campaign coverage**, not completed scientific results. The master controller is still observing Phase 1. A phase becomes scientifically complete only after its registered training, common evaluations, analysis, and verified private Hugging Face archive finish. At the time of this audit, later phase outcomes and final conclusions are pending.

The **optional** designation applies to execution decisions. The implementation, registration, calibration path, measured-time gate, skipped-run reason, and report path exist for each optional arm. A gate can legitimately reject an experiment when its evidence or remaining VM time is insufficient. Gate decisions are frozen in JSON before an optional run is trained.

The current focused code verification is **36 passing post-hackathon/causal tests** plus Python compilation of the campaign scripts. The tests include PHM materialization and parameter budgets, depth-growth parity, MoE birth/catch-up/active-compute accounting, bounded on-policy replay, reference KL, paired uncertainty, checkpoint interruption, and a tiny Differential-Co4 CPU attention profile. Pinned post-training dataset paths and example schemas were checked against their exact Hugging Face revisions. The full post-training data were built and archived; the first 4,000 SFT examples now contain 2,000/2,000 generic sources, approximately 1,333 of each aligned source, and 1,000 of each directly tuned task source. A real-data tokenizer check found that 196 of the first 1,333 aligned SciQ prompts exceed context 256 but all retain the trailing question after left truncation; three of the first 4,000 task-tuned PIQA answers exceed the completion window and are now excluded by the registered loader policy. The limited prompt-audit smoke test exercised all eight task builders; the full audit remains scheduled in Phase 2. These checks do not substitute for completed training results or guarantee that future long runs cannot expose bugs.

**Data defects corrected in this pass:** the previous bounded SFT cursor traversed contiguous dataset groups and would not reach most sources before the one-million-token endpoint. The new order policy is registered before any P0–P4 experiment exists. The loader now excludes completions longer than the model context and logs the exclusion count. A separate private archive receipt makes the pinned data upload restartable if a later phase retries after a partial upload.

**Scheduling limit still present:** the live controller recomputes remaining time, protects the 12-hour archive reserve, and rejects an experiment whose registered endpoint cannot fit. It does not yet replace the already-registered 150M-token 16M control pair with a newly matched 100M-token pair if throughput worsens. Shortening only later candidate arms to 100M would break the matched-token comparison, so the current controller protects scientific comparability and may skip those screens instead. The execution prompt's explicit 16M contraction rule is therefore not fully implemented. This is a real coverage limit, not a completed phase or an optional-arm decision.
